\# Redes de Computadores — UFSC



Practical assignments completed as part of the Computer Networks course at the Federal University of Santa Catarina (UFSC), Brazil.



\## TP2 — Network Monitoring with PRTG



\- Monitored a local Wi-Fi network using PRTG Network Monitor.

\- Observed network traffic and packet rates.

\- Monitored router availability and ping response times.

\- Analyzed ICMP Echo Request and Echo Reply packets using Wireshark.

\- Collected and exported monitoring data in CSV format.



\*\*Files:\*\* report, CSV measurements and ICMP packet capture.



\## TP3 — Network Protocol Analysis with Wireshark



\- Analyzed ARP address resolution.

\- Examined TCP connection establishment and termination.

\- Inspected HTTP requests and responses.

\- Observed UDP traffic and SSDP messages.

\- Studied packet captures using Wireshark.



\*\*Files:\*\* report and PCAPNG packet captures.



\## Tools



\- PRTG Network Monitor

\- Wireshark

\- TCP/IP networking

\- CSV data analysis
